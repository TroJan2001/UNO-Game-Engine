# UNO Game Engine

A fully customizable **UNO game engine** implemented in Java.  
Designed with a focus on **clean code, design patterns, and extensibility**, allowing developers to build traditional UNO gameplay or extend it with new rules and card types.

## Features
- Core UNO gameplay mechanics (draw, play, skip, reverse, wild, draw-two, etc.)
- **Custom rule support**: easily add new rules, actions, or card types
- **Extensible engine design** with Object-Oriented principles and design patterns
- **Separation of concerns** between game logic, rule enforcement, and UI
- Flexible enough for CLI, GUI, or networked versions to be built on top

## Tech Highlights
- Java • OOP Principles • Design Patterns (Factory, Strategy, Observer, etc.)
- Modular architecture for maintainability and scalability
- Emphasis on reusability and adaptability for new game variants

## Project Context
Developed to practice **clean architecture, design patterns, and extensible Java systems**, demonstrating how complex game logic can be abstracted into a reusable engine.
